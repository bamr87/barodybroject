{% comment %} File: model_table.html Description: Reusable dynamic table for displaying model lists with sorting and filtering Author: Barodybroject Team Created: 2025-11-25 Last Modified: 2026-08-31 Version: 1.2.0 Dependencies: - custom_filters template tag library - table_utils.js for sorting/filtering functionality Contract with table_utils.js (both halves must hold, or the feature is dead): - Every sortable header carries `class="sortable"` — that is the exact selector table_utils.js binds its click handler to. Without it no listener is attached and clicking a column header does nothing at all. - A header whose values are not plain text carries `data-type="number"` or `data-type="date"` (emitted by the `sort_data_type` filter), which selects sortTable's comparator. A header with no data-type sorts lexicographically. - The per-column filter is an `input.filter` nested inside its ``; table_utils.js maps it back to a column via `input.closest('th').cellIndex`, and ignores clicks originating inside it so typing never re-sorts. - There are TWO empty states, and they mean different things. The `{% empty %}` row ("No items found") means the SERVER returned nothing. The `tr[data-filter-empty]` row ("No matching records") means rows exist but the active filters match none of them; it ships hidden and filterTable() toggles it. Without that row the table body just empties in silence, which is what issue #96 reported. Remove it and the message disappears — the JS never builds one.
